## Asset Naming Convention

When adding assets, follow this format:

- **Logos:** `logo_{variant}_{size}.{ext}`
  - Example: `logo_primary_500x500.png`
- **Icons:** `icon_{purpose}_{size}.{ext}`
  - Example: `icon_email_64x64.svg`
- **Media:** `{type}_{subject}_{YYYY-MM-DD}.{ext}`
  - Example: `photo_office_2025-07-16.jpg`
- **Design Files:** `{project}_{purpose}.{ext}`
  - Example: `ZKRevenueOps_proposal_cover.fig`

---

## How to Add an Asset

1. Save the asset file to the correct subfolder in 06_Resources.
2. Add an entry to this catalog with all metadata.
3. Ensure the file name follows the asset naming convention.
4. If the asset is >50MB, flag for review and consider compression.
5. Log the addition in `08_Logs/Change-Logs/`.
