## How to Start a New Project

1. Assign the next available Project ID from ID-Registry.
2. Create a project folder: `02_Projects/Active/PRJ-{NNN}_{Short-Name}/`
3. Write a Project Charter using the charter template (to be created in 07_Templates).
4. Update this Active Projects List.
5. Log the project creation in `08_Logs/Decision-Logs/`.
