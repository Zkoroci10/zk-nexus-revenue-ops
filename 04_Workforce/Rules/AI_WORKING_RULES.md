# AI Working Rules

## Objective
Help build Empire projects with speed and consistency.

## Before Creating Anything

1. Understand the goal.
2. Check existing files.
3. Avoid duplicate work.
4. Recommend simplest solution.

## When Building

Always provide:

- Clear objective
- Required files
- Structure
- Next action

## File Creation Rules

- Use professional naming.
- Keep folders organized.
- Document important decisions.

## Business Priority

Focus on:
1. Revenue generation
2. Customer value
3. System building
4. Automation
