## 1. Observation

Direct empirical observations from source analysis and terminal execution:

1. **Source Code Integrity (`db_engine.js`)**:
   - Lines 485–572 (`seed100kLeads`): Utilizes `DatabaseSync` to open transaction `BEGIN TRANSACTION;`, executes parameterized insert `INSERT INTO buyer_prospects (...) VALUES (...)` for 100,000 lead objects generated by `generate100kLeads()`, and commits transaction `COMMIT;`.
   - Lines 242–290 (`calculateDSR`): Implements exact formula `estInstallment = Math.round(maxBudget * 0.0048)` and `dsrPercent = Math.round(((existingCommitments + estInstallment) / netIncome) * 100)`. Assigns Grade A (DSR <= 65%), Grade B (66-75%), Grade C (>75%). Returns dynamic calculation metadata without hardcoded static responses.
   - Lines 139–146 (`initSchema`): Drops/re-creates 5 explicit B-Tree indexes:
     - `idx_buyer_dsr_grade` ON `buyer_prospects(grade, dsr_percent)`
     - `idx_buyer_status_score` ON `buyer_prospects(status, lead_score DESC)`
     - `idx_buyer_location_budget` ON `buyer_prospects(preferred_location, max_budget)`
     - `idx_buyer_ren_allocation` ON `buyer_prospects(allocated_ren_id, status)`
     - `idx_buyer_sla` ON `buyer_prospects(sla_status, sla_deadline)`
   - Lines 298–478 (`allocateLead` & `checkSLAEscalations`): Priority routes qualified enterprise leads (Grade A / budget >= RM1M / score >= 80) to Enterprise tier RENs with a 5-minute SLA timer (`sla_deadline = now + 5 min`, `sla_status = 'PENDING'`). Standard leads use `DYNAMIC_ROUND_ROBIN`. Breached SLA leads (`sla_deadline < now`) are auto-escalated to alternate Enterprise RENs with `sla_status = 'BREACHED_REALLOCATED'`.
