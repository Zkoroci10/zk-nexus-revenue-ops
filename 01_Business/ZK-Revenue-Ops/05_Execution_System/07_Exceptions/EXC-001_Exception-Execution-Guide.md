# EXC-001 — Exception Execution Guide

1. **Duplicate Lead**: Gabung nota perbualan ke kad asal. Tag kad baharu `Duplicate Archived`.
2. **Invalid Phone Number**: Mark `Tier 3 Disqualified (Invalid Number)` & tamatkan workflow.
3. **Lead Marah / Opt-Out**: Minta maaf secara mesra, tag `Archived (Opt-Out)`, hentikan mesej serta merta.
4. **Appointment Cancelled**: Tawarkan 2 slot tarikh baharu. Jika enggan, mark `Closed Lost`.
