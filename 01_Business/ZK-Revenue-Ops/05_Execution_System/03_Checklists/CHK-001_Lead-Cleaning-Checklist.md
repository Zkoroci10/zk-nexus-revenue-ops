# CHK-001 — Lead Cleaning Checklist

- [ ] Nama lengkap diisi mengikut format *Proper Case*.
- [ ] Nombor telefon disahkan dalam format Malaysia (`+601...`).
- [ ] Semakan duplikasi nombor 30 hari selesai (Tiada rekod bertindih).
- [ ] Status pipeline ditetap kepada `📥 New Lead`.
- [ ] `client_id` pemilik REN ditetap tepat mengikut *Territory Lock*.
- [ ] Tag sumber (`source`) diletakkan (FB Ads / TikTok / iProperty / Guru).
