# ZK-FEAT-002 — Operator Task & Action Console

## Goal
Menyediakan paparan kerja berpusat (*High-Speed Task Console*) untuk Virtual SDR memproses saringan DSR dan siri susulan.

## User
Virtual SDR Operator.

## Workflow
`Task List Queue` ➔ `Click Task Card` ➔ `View AI/Template Suggested Message` ➔ `Click Approve & Send`.

## UI Components
* **Task Queue List**: Diisih mengikut keutamaan P1 SLA Alert & masa due.
* **Suggested Message Bar**: Draf mesej sedia terisi dengan nama pembeli & projek.
* **1-Click WhatsApp Trigger**: Butang `Approve & Send` pantas.

## Business Rules
`SLA-001` (Speed-to-lead <5m), `OR-002` (Script Compliance).

## KPI
* **Speed-to-lead Compliance**: > 95%.
