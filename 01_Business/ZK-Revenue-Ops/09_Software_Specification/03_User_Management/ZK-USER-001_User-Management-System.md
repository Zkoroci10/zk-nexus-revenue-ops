# ZK-USER-001 — User Management System

> **ZK-USER-001 | Spesifikasi Pengurusan Pengguna & Akaun (User Management)**

---

## Purpose

Dokumen ini mendefinisikan **Spesifikasi Pengurusan Pengguna (*User Management*)** yang mengawal pendaftaran akaun, pengesahan identiti (*Authentication*), dan profil pengguna platform.

---

## Core User Modules

1. **Authentication Engine**: Magic Link / Passkey Login tanpa kata laluan rumit.
2. **Account Registration**: Pendaftaran kerusi eksklusif `SEAT-001` hingga `SEAT-030` yang dikunci oleh Founder.
3. **Profile Settings**: Tetapan maklumat REN (Nama, No REN LPPEH, Agensi, Zon Hartanah Fokus).
4. **Subscription Management**: Pemantauan status retainer bulanan dan tarikh pembaharuan invois.
