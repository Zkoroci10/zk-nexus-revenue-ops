# ZK-UI-001 — UI/UX Design System Specification

> **ZK-UI-001 | Spesifikasi Reka Bentuk UI/UX & Komponen Visual (UI/UX Design System)**

---

## Purpose

Dokumen ini mendefinisikan **Spesifikasi Reka Bentuk UI/UX (*UI/UX Design System*)** untuk memastikan paparan perisian kelihatan moden, premium, dan mudah digunakan pada telefon bimbit mahupun desktop.

---

## Design System Tokens & Components

1. **Color Palette**: Dark Mode Premium (Slate Dark `#0F172A`, Accent Emerald Green `#10B981`, Warning Amber `#F59E0B`, Alert Red `#EF4444`).
2. **Typography**: Google Fonts Inter / Outfit (Clean Sans-Serif).
3. **Core UI Components**:
   * **Global Search Bar**: Carian pantas nombor telefon/nama (`Ctrl + K`).
   * **Filter Dropdown**: Penapis status, tarikh, & projek.
   * **Status Badge**: Lencana berwarna (`🔥 Tier 1 Hot`, `🌤️ Tier 2 Warm`, `📅 Viewing Booked`).
   * **Action Button**: Butang tindakan 1-Click (`Approve & Send`, `Dispatch Waze`).
4. **Interface States**:
   * **Empty State**: *"Tiada tugasan beratur. Semua lead disokong 100%!"*
   * **Error State**: *"Koneksi WhatsApp Terputus. Sila Imbas QR Code semula."*
