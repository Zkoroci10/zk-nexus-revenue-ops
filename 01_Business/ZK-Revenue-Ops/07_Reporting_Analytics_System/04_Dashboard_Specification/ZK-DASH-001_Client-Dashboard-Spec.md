## Core Question Answered
*"Adakah lead saya bergerak dan berapa temujanji viewing sedia ada?"*

---

## Dashboard Widgets & Display Components

```text
┌────────────────────────────────────────────────────────────────────────┐
│                      CLIENT PORTAL NOTION DASHBOARD                    │
├─────────────────────┬───────────────────┬──────────────────────────────┤
│ TOTAL LEADS: 150    │ HOT LEADS: 24     │ CONFIRMED VIEWINGS: 8        │
├─────────────────────┴───────────────────┴──────────────────────────────┤
│ 📋 KANBAN BOARD VIEW:                                                  │
│ [📥 New] ➔ [🔍 Screening] ➔ [🔥 Hot] ➔ [📅 Booked] ➔ [💰 Closed]       │
├────────────────────────────────────────────────────────────────────────┤
│ 📊 ESTIMATED PIPELINE COMMISSION VALUE: RM 72,000                      │
│ 📝 RECENT ACTIVITY LOG: [10:30am] New Viewing Booked for Unit 12-A     │
└────────────────────────────────────────────────────────────────────────┘
```

1. **Total Leads Count Card**: Jumlah keseluruhan lead aktif terkumpul.
2. **Hot Leads Counter**: Lead Tier 1 yang sedia untuk temujanji.
3. **Confirmed Viewings Counter**: Temujanji viewing fizikal terkunci minggu ini.
4. **Pipeline Value Counter**: Anggaran jumlah nilai komisyen hartanah terkunci (RM).
5. **Interactive Notion Kanban Board**: Paparan seret-dan-lepas (*Drag-and-Drop*) fasa lead real-time.
6. **Recent Activity Feed**: Log perbualan & penyerahan Dossier terkini.
