# ZK-DASH-003 & ZK-DASH-004 — Admin & Executive Dashboard Specs

## ZK-DASH-003: Admin Operations Dashboard
* **Core Question**: *"Adakah operasi keseluruhan 30 pelanggan REN berjalan lancar?"*
* **Widgets**: All Clients Overview Table, Operator Performance Leaderboard, SLA Breaches Log, System Gateway Health Status, Quality Score Distribution.

---

## ZK-DASH-004: Executive Control Dashboard (Founder View)
* **Core Question**: *"Seberapa sihat kewangan, retainer MRR, dan ROI perniagaan ZK Revenue Ops?"*
* **Widgets**:
  * **30-Cap Seat Utilization Gauge**: Bilangan Kerusi Aktif (`SEAT-001` hingga `SEAT-030`).
  * **Monthly Recurring Revenue (MRR)**: Jumlah yuran retainer terkumpul.
  * **Gross Commission Pipeline**: Jumlah anggaran komisyen dalam ekosistem.
  * **Net ROI Multiplier**: Purata pulangan komisyen pelanggan REN (Target 3x-5x).
